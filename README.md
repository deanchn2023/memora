# 忆境 Memora v2.6

> **你的个人 AI 记忆助理，越用越懂你**

Memora v2.6 是一个深度集成 AI 的桌面应用，AI 不是附加功能，而是系统运转的核心引擎。从你复制的一段文字开始，到知识的沉淀与唤醒，AI 全程参与、持续学习、自我优化。

---

## 🆕 v2.6 新特性

### 专家团系统（Group Chat Engine）

多专家协同处理复杂任务，主持人智能调度：

```
用户提出复杂需求
    → 主持人分析需求，拆解为子任务
    → 精准分配给最擅长的专家
    → 各专家并行/串行独立处理
    → 主持人汇总输出最终方案
```

| 特性 | 说明 |
|------|------|
| **主持人调度** | 深度分析需求 → 精准匹配专家 → 分配具体任务 → 汇总产出 |
| **专家池** | 可配置多个专家，每个专家有独立名称、图标、专业领域、ADP AppKey |
| **执行策略** | 支持 `parallel`（并行）和 `serial`（串行）两种模式 |
| **流式输出** | 所有专家回复实时流式渲染，80ms 刷新频率 |
| **文件卡片** | 专家输出中的文件链接自动转换为可保存/打开的文件卡片 |
| **JSON 智能渲染** | 主持人返回的 JSON 自动解析为可读格式（需求分析/初步判断/任务分配） |
| **动态增删** | 支持运行时增删专家，即时生效 |

### v2.5 新增功能

- **ADP Claw 模式文件对话**：支持上传文件到 ADP 智能体进行文档分析
- **AI 学习顾问**：五维雷达图展示学习状态
- **易错知识 AI 总结**：分析薄弱知识点生成学习建议
- **每日单词系统**：中心词扩展记忆法 + 间隔重复 + AI 学习计划

## 核心 AI 功能

### 1. 剪贴板智能感知 — 无感录入，精准识别

当你复制任何文字，AI 在 3 秒内完成三重判断：

| 判断维度 | AI 输出 | 举例 |
|---------|--------|------|
| **待办识别** | `is_task: true/false` + 优先级 + 截止时间 | "@Dean 你整理一下方案" → 待办，高优先级 |
| **信息有效性** | `is_valid_info: true/false` + 分类 + 摘要 | 产品规格参数 → 有效信息，保存 |
| **知识推荐** | `needs_recommendation: true/false` + 意图 | "这个方案怎么接入？" → 需要推荐，触发搜索 |

### 2. 专家团系统 — 多专家协同处理复杂任务

主持人根据需求智能调度专家团：

```
用户需求 → 主持人深度分析
    ├→ 拆解为具体子任务
    ├→ 按专业领域精准匹配专家
    ├→ 并行/串行执行（可配置策略）
    └→ 汇总所有专家产出 → 最终方案
```

- **主持人 Prompt 优化**：要求按专家职能精准分配，task 描述包含上下文+具体要求+期望输出
- **JSON 智能渲染**：主持人返回的 JSON 自动解析为分段式 UI（需求分析/初步判断/任务分配卡片）
- **文件卡片**：专家输出中的文件链接自动转换为可保存/打开的卡片
- **流式输出**：80ms 刷新频率，实时渲染专家回复

### 3. 语义记忆提取 — 从文字到结构化记忆

AI 将碎片文本转化为结构化记忆，自动完成：

- **记忆分层**：瞬时（instant）→ 短期（short）→ 长期（long）
- **内容分类**：task / interest / person / project / goal / knowledge / action
- **实体提取**：识别人物、公司、产品、技术、项目等实体
- **摘要生成**：50 字以内精准摘要
- **关联发现**：自动匹配高频人物和活跃项目

### 4. 知识萃取引擎 — 从碎片到体系

```
阶段一：知识原子提取
    笔记内容 → AI 提取最小知识单元（fact/rule/insight/procedure/question）

阶段二：AI 智能聚类
    未归簇原子 + 已有簇 → AI 按主题智能分组

阶段三：知识文章合成
    成熟簇（≥5个原子）→ AI 合成结构化 Markdown 文章
```

### 5. 多意图 Agent 系统 — 一个入口，五个专家

| Agent | 意图 | 能力 |
|-------|------|------|
| **Priority Agent** | priority | 综合截止时间、优先级偏好、工作时段排程 |
| **Knowledge Agent** | knowledge | 碎片笔记聚类、合并建议、洞察提取 |
| **Memory Agent** | memory | 记忆晋升/降级/淘汰/合并建议 |
| **Report Agent** | report | 自动生成日报/周报 |
| **Chat Agent** | chat | 上下文感知通用对话 |

### 6. ADP 智能体集成 — 企业级知识库对话

集成腾讯 ADP V2 智能体平台，支持：
- **流式 SSE 对话**：实时渲染 AI 回复
- **Claw 模式文件对话**：上传文件到智能体进行文档分析
- **三密钥体系**：通用对话 / 知识推荐 / 搜索问答
- **结果自动保存**：AI 回复自动归入知识推荐列表

## AI 自学习与自我优化

### 反馈闭环系统（Feedback Loop）

```
AI 输出 → 用户操作（接受/删除/修改）
    → 反馈记录（trace_id + 正/负标签）
    → 注入后续 Prompt 的正/负样本
    → AI 下次遇到相似输入时参考历史判断
```

### 用户画像自适应

| 维度 | 数据来源 | AI 影响 |
|------|---------|--------|
| 高频人物 | 剪贴板/笔记中的人名频率 | 影响记忆分层 |
| 活跃项目 | 任务/笔记中关联的项目 | 影响待办识别 |
| 优先级偏好 | 用户的优先级调整历史 | 影响新任务优先级 |
| 工作时段 | 任务完成时间分布 | 影响排程建议 |

## 技术架构

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 28 |
| 前端 | 原生 HTML/CSS/JS（Apple Design Language） |

| 反馈系统 | trace 日志 + 正/负样本自动注入 |
| 配置服务 | 远程配置 + 本地配置双通道 |
| 国际化 | i18n 中英文运行时切换 |

## 隐私与安全

- **数据本地优先**：所有记忆、笔记、知识原子、文章均存储在本地，不上传云端
- **AI 调用最小化**：只在需要智能分析时调用 AI，基础操作无需 AI
- **反馈数据本地存储**：正/负样本日志不外传
- **Token 安全**：API Key 通过环境变量或远程配置注入，不硬编码
- **组织配置隔离**：不同组织的 ADP 密钥、Prompt 模板完全隔离
