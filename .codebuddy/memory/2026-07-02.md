## CC 查询超时问题修复（M-Agent 模式）
**问题**: 用户在智能助手 M-Agent 模式下进行 CC 查询时失败，耗时 1223 秒（101步），最终超时

**根因分析**:
1. 后端 httpx 超时时间过短（60s）- Agent 平台知识库查询往往需要 1-3 分钟
2. 前端 axios 没有设置超时时间 - 用户无法判断是否卡住
3. 缺乏诊断日志 - 难以定位真正的瓶颈

**修复内容**:
1. **backend/app/agent/client.py**: 
   - httpx 超时从 60s → 300s
   - 添加日志记录（新建 logger.py）
   - 在 invoke() 中加入 InvokeTimer 计时和错误诊断

2. **frontend/src/api/index.ts**: 
   - axios 超时从无限制 → 350s（给后端 300s + 50s 网络缓冲）

3. **frontend/src/pages/KnowledgeQA.tsx**: 
   - 添加前端兜底超时检测（300s）
   - 改进错误处理与用户提示
   - 显示详细错误信息和重试建议

4. **backend/main.py**: 
   - 增加注释说明超时配置策略
   - 添加 CORS 中间件（去重复配置）

**修复文档**: `/Users/congkunzhu/Library/Application Support/memora/cc-workspace/rd-efficiency-platform/docs/CC-QUERY-TIMEOUT-FIX.md`
