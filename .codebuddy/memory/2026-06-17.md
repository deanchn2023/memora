## AI 定时任务 Bug 修复（第二轮）
- **根因**：`_executeAITask()` 调用 `this.switchView('aiAssistant')` 但 `switchView` 方法在 `App` 对象上不存在（从未定义），导致 TypeError 中断执行
- **修复**：
  1. `app.js`：`this.switchView('aiAssistant')` → `this.showAIAssistantView()`（App 上已有的正确方法）
  2. `reminder.js`：`window.App?.switchView('calendar')` → `window.Calendar?.showCalendarView()`（直接切换日历视图）
- **教训**：调用不存在的方法是静默失败（async 中被 catch 吞掉）还是 TypeError 取决于 try/catch 位置。此例中 `switchView` 不在 try 内，直接导致整个 `_executeAITask` 中断

## 人脉图谱交互修复（3项）

### 问题1：无法点选节点查看
- **根因**：Canvas 点击坐标转换未考虑 CSS transform（scale+translate），导致命中检测偏移
- **修复**：`canvas.addEventListener('click')` 中将屏幕坐标通过 `(clientX - rect.left - panX * scale) / scale` 反算为 Canvas 绘图坐标
- **增强**：命中半径从 `n.radius` 增加到 `n.radius + 5`，方便点击
- **新增**：Canvas mousemove 事件，hover 节点时 cursor 变 pointer

### 问题2：点选左侧人名未以该人为中心
- **根因**：左侧卡片点击仅调用 `_showPersonDetail` + `_drawGraph`（重新模拟），未将图谱中心对准选中人物
- **修复**：
  - 新增 `_centerOnPerson(personId)` 方法：计算 `panX = w/2 - node.x + detailShift`，`panY = h/2 - node.y`，应用 CSS translate
  - 新增 `_applyCanvasTransform()` 方法：统一设置 `transform: translate(panX, panY) scale(scale)` + `transform-origin: 0 0`
  - 新增 `_renderGraphFrame()` 方法：仅重绘帧不重新模拟（用于高亮切换）
  - 左侧卡片/canvas节点/关联人脉点击均调用 `_centerOnPerson` + `_renderGraphFrame`
  - 关闭详情面板时恢复居中（对准"我自己"节点或重置 panX/panY）

### 问题3：详情卡片挡住图谱
