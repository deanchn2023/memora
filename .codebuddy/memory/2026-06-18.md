# 2026-06-18 工作日志

## 人脉图谱交互增强

重构 `relationship.js` 和 `relationship.css`，参考知识图谱 `ForceLayout` 的交互设计，为人脉图谱增加完整交互能力：

### 新增交互功能
1. **节点拖拽**：mousedown 命中节点后可自由拖动位置
2. **画布平移**：mousedown 空白区域后可拖动画布
3. **滚轮缩放**：以鼠标位置为中心缩放（0.2x~5x），替换旧的 CSS 变换方式
4. **点击高亮一级关联**：点击节点自动高亮其直接关联的人和边，其余暗化
5. **双击展开二级关联**：双击节点扩展到二级关联节点
6. **关联级别按钮**：工具栏 1°/2°/◉ 按钮切换关联层级
7. **框选模式**：工具栏 ⬚ 按钮切换框选模式，拖动选择多个节点
8. **适配视图**：⊞ 按钮自动缩放平移让所有节点可见
9. **重置布局**：⟲ 按钮重新模拟力导向布局
10. **聚焦动画**：选中节点后平滑过渡到居中位置
11. **触摸支持**：单指拖拽/平移，双指缩放

### 架构变更
- **Canvas 级变换**：移除 CSS `transform` 方案，改用 `ctx.translate/scale` 实现缩放平移
- **`_transform` 对象**：`{ x, y, scale }` 管理视图变换状态
- **`_getHighlightedNodeIds()`**：计算指定层级内的关联节点集合
- **`_hitTest()` / `_screenToGraph()`**：屏幕坐标↔图谱坐标转换
- **`_focusOnPerson()`**：带动画的聚焦（替代旧的 `_centerOnPerson`）
- **`_fitView()`**：自动适配视口
- **`_selectNodesInRect()`**：框选节点逻辑

### 工具栏 UI
旧：3个按钮（+/-/⟲）→ 新：分组工具栏，含缩放组、视图组、关联组、框选组，底部居中显示
