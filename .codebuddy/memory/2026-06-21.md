## 修复：M-Agent 模式打包后 spawn ENOTDIR

**根因**：Claude Agent SDK 通过 `import.meta.url` → `fileURLToPath` → `dirname` → `resolve` 定位原生 `claude` 二进制文件。打包后 `import.meta.url` 解析到 `app.asar` 内部路径。虽然 `asarUnpack` 已将文件解包到 `app.asar.unpacked`，但 SDK 仍用 asar 路径调用 `spawn()`，OS 发现 `.asar` 是文件而非目录 → `spawn ENOTDIR`。

**SDK 内部逻辑分析**：
1. `getDefaultExecutable()` 返回 `"node"`（Electron 运行在 Node.js 而非 Bun）
2. `ZT()` 函数在 `dirname(import.meta.url)` 下查找 `@anthropic-ai/claude-agent-sdk-{platform}-{arch}/claude`
3. `OB()` 检查路径不以 `.js/.mjs/.tsx/.ts/.jsx` 结尾 → 判定为原生二进制 → 直接 `spawn(path)` 而非 `spawn(node, [path])`
4. asar 路径被直接传给 `spawn()` → ENOTDIR

**修复**（`main.js` `cc:invoke` handler）：打包模式下显式计算 `app.asar.unpacked` 中的正确二进制路径，通过 `pathToClaudeCodeExecutable` 选项传给 SDK，跳过其内部 `import.meta.url` 路径解析。

**验证**：打包后 `app.asar.unpacked/node_modules/@anthropic-ai/claude-agent-sdk-darwin-arm64/claude` 存在且可执行（214MB，0o755 权限）。

## 修复：M-Agent 后台执行 + 完成通知

**用户反馈**：M-Agent 执行 602s 后显示 "Claude Code process aborted by user"，用户担心离开页面导致执行中断。

**分析结果**：
1. **离开页面不会停止 CC 执行** - CC 进程在 `main.js` 中独立运行（async IIFE），切换视图只隐藏 DOM，`onCCStream` 监听器仍活跃
2. **602s 超时是 10 分钟限制触发** - `CC_TIMEOUT_MS = 10 * 60 * 1000`（600s），加传播开销 = 602s
3. **CC 模式缺少完成通知** - `_finishADPMessage` 有 `_notifyADPCompleted`，但 `_finishCCMessage` 没有调用它
4. **与多任务设计无冲突** - TaskManager 是并行模式专用，单任务 CC 走 `cc:invoke` 独立通道

**修复内容**：
1. `app.js` `_finishCCMessage`：添加 `_notifyADPCompleted` 调用，CC 完成后用户在别的页面也能收到系统通知 + 声音提醒
2. `app.js` `_notifyADPCompleted`：预览选择器增加 `.chat-markdown-content` 匹配 CC 输出
3. `main.js`：CC 超时从 10 分钟增加到 30 分钟（复杂任务如代码生成需要更长时间）

## 修复：供应商与模型列表未关联（火山引擎显示 OpenRouter 模型）

**问题**：AI 助手页面选择"火山引擎"供应商后，模型列表仍显示 OpenRouter 的模型列表。

**根因**：竞态条件。`_loadCCConfig` 回调中先调用 `_initOpenRouterModelSelector()`（async 不 await，发 HTTP 请求获取 OpenRouter 模型），紧接着调用 `_initProviderSelector()`（async 不 await，快速设置供应商并调用 `_updateModelSelectorForProvider('volcano')` 加载火山引擎模型）。由于 OpenRouter HTTP 请求耗时长，它在 `_updateModelSelectorForProvider` 正确设置火山引擎模型后**异步覆盖**了模型下拉框。

**修复**（`src/scripts/app.js`）：
1. 移除 `_loadCCConfig` 回调中无条件的 `_initOpenRouterModelSelector()` 调用，改由 `_initProviderSelector` → `_updateModelSelectorForProvider` 根据当前供应商自动加载对应模型
2. 移除工作目录切换时无条件的 `_initOpenRouterModelSelector()` 调用
3. `_initOpenRouterModelSelector` 增加守卫：当前供应商非空且非 openrouter 时，跳过加载

### Bug 修复：全屏后高度未达到窗口尺寸（已修复）
**问题**：全屏后 `.body.font-small` 高度只有 948px，未达到全屏窗口高度。

**根因**：`#app` 使用 `height: 100vh`，但在 Electron 全屏时 `100vh` 可能不等于实际窗口高度。需要使用 `position: fixed` 并设置 `top/left/right/bottom: 0` 来确保填满整个窗口。

**修复**：

3. **main.css** — `.content` 添加 `height: 100%`
4. **main.css** — `.main-view` 添加 `height: 100%`

### Bug 修复：全屏后高度未达到窗口尺寸 — zoom 根因（已修复）
**问题**：全屏后 `body.font-small` 高度只有 948px（应为 ~1080px），底部留白。

**根因**：`body.font-small { zoom: 0.9 }` 会把整个页面缩小到 90%，但 `#app { height: 100vh }` 仍然是视口原始高度（1080px），缩小后视觉上只占 90%（972px），底部留出 10% 空白。之前的 `position: fixed` 修复无效，因为 zoom 会影响 fixed 元素。

**修复方案**：用 CSS 变量 `--zoom-factor` 补偿 zoom 缩放：
1. **appearance.css** — `body.font-small { --zoom-factor: 0.9; zoom: 0.9; }`，medium=1，large=1.1
2. **main.css** — `#app { height: calc(100vh / var(--zoom-factor, 1)); min-height: calc(100vh / var(--zoom-factor, 1)); }`，移除 `position: fixed` 和之前的 workarounds
3. **components.css** — 周视图高度也改为 `calc(100vh / var(--zoom-factor, 1) - 220px)`

原理：`100vh / 0.9 = 1200px`，经过 `zoom: 0.9` 后视觉高度 = `1200 * 0.9 = 1080px`，正好填满窗口。

### Bug 修复：剪贴板扫描整天不工作 — isAnalyzing 卡死（已修复）
**问题**：剪贴板扫描一整天不触发。

**根因**：`auditedDeepSeekCall` 的 `fetch` 调用没有超时保护。当 API 服务器无响应或网络异常时，`fetch` 永远挂起，导致 `analyzeClipboardText` 永远不 resolve，进而 `ClipboardScheduler.isAnalyzing` 永远为 `true`，所有后续剪贴板变化都被跳过（加入 pending 队列或丢弃）。

**修复**（两层防御）：
1. **main.js `auditedDeepSeekCall`**：`fetch` 无 `signal` 时自动创建 `AbortController`，30s 超时后自动中断
2. **ClipboardScheduler `_doAnalyze`**：设置 `isAnalyzing=true` 时同时启动 60s 安全重置定时器；超时后强制 `isAnalyzing=false` 并处理 pending 队列
3. **ClipboardScheduler 心跳日志**：`isAnalyzing` 时显示已持续秒数，方便排查
4. **清理**：`onAnalysisComplete`、`catch`、`stop()` 中都清理安全重置定时器

**根因**：原代码在检测到 Ctrl/Cmd/Shift+Enter 时仅 `return` 退出处理函数，依赖浏览器默认行为插入换行。但在 Electron/Chromium 的某些情况下（特别是 macOS），textarea 的默认行为可能不插入换行符。

**修复**（`app.js`）：改为显式插入换行符：
1. `e.preventDefault()` 阻止默认行为
2. 用 `selectionStart/selectionEnd` 获取光标位置
3. 在光标处插入 `\n` 字符
4. 调整光标位置到换行符后
5. `dispatchEvent(new Event('input'))` 触发自动调整高度
