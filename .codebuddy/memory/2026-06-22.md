### 新功能：记事本拖拽合并
在记事本列表中，将一个记事项拖拽到另一个记事项上方，即可合并两个记事项。

**实现细节**：
- `notebookList` 上新增 `dragover/dragenter/dragleave/drop` 事件，检测笔记项之间拖放
- 拖入目标笔记项时显示蓝色高亮 + "⬇ 合并" 标签（`.merge-drop-target` CSS 类）
- 释放时弹出确认弹窗，确认后合并内容（分隔线连接）+ 合并标签（去重）+ 删除来源
- `mergeNotes(sourceId, targetId)` 方法：读取两条笔记 → 合并 content/htmlContent/tags → 更新目标 → 删除来源 → 刷新列表
- `dragend` 时清理所有 `merge-drop-target` 高亮

### Bug 修复：AI 小助手 Skill 和模型选择不生效（已修复）
**问题**：AI 小助手选择了 Skill 后发送消息，Skill 没有被调用；模型选择也未生效。

**根因**：
1. ADP 模式（agent）：`sendADPMessage` 不传递 skill/model 信息
2. LLM 模式：`agent.invoke` 不传递 skill/model 信息
3. CC 模式已正确传递 ✅

**修复**：
- **app.js ADP 模式**：读取 `ccSkillSelect`/`ccOpenRouterSelect`/`ccProviderSelect`，注入 skill 到 `systemRole`，传递 `modelHint`/`providerHint` 到 `sendADPMessage`
- **app.js LLM 模式**：读取 `ccSkillSelect`/`ccOpenRouterSelect`，skill 注入消息前缀，model 作为第四参数传给 `agent.invoke`
- **preload.js**：`agent.invoke` 增加 `model` 参数
- **main.js `agent:invoke`**：解构 `model: userSelectedModel`，覆盖 `apiConfig.model`
