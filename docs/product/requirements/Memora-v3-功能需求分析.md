# Memora v3.0 功能需求分析 — 有价值有痛点的方向

> 基于 v2.5.0 已有 60+ 模块、235+ IPC 的功能全貌，从**用户痛点**和**差异化价值**两个维度筛选。

---

## 评估标准

| 维度 | 评分标准 |
|------|---------|
| 痛点强度 | 解决用户日常高频困扰（不是"有了更好"，是"没有难受"） |
| 差异化 | 市面上少见/没有的能力，不是 Notion/Obsidian 的简单复制 |
| AI 原生度 | 让 AI 做更多自动化，人工只确认决策（符合 Memora AI 原则） |
| 实现成本 | 不需要大规模重构，可在现有架构上增量实现 |
| 用户感知 | 用户能明显感知到"这个功能帮我省了大量时间" |

---

## S 级需求（强烈推荐，痛点最强）

### S1. 智能周回顾 — "AI 读懂你的一周"

**痛点**：一周结束，做了很多事但说不清价值；周报靠回忆，遗漏重要进展；任务碎片化，看不到整体轨迹。

**方案**：
- 每周五下午自动触发（可配置时间），AI 汇总本周：
  - 完成的任务 + 番茄时长 + 专注度评分
  - 新增记忆/笔记/知识原子的主题聚类
  - 剪贴板高频词云（你这周最关注什么）
  - 知识缺口提示（"你这周3次提到 K8s，但知识库没有相关记录"）
  - 下周建议（基于未完成任务 + 即将到期事项 + 知识缺口）
- 输出：可视化卡片面板 + Markdown 导出 + 可直接发到工作群

**AI 原生度**：高 — 全程 AI 分析聚合，用户只需看结果
**差异化**：Notion 周报是手写的，Memora 是自动生成的

---

### S2. 剪贴板工作流 — "复制即执行"

**痛点**：复制一段会议纪要 → 需要手动拆分任务、提取关键人、记录决策点、设提醒……反复操作，AI 分析了但后续动作仍需多步手动。

**方案**：
- 剪贴板分析结果支持**一键工作流**，自动串联多个操作：
  - **会议纪要工作流**：提取待办（创建任务）→ 提取决策点（保存笔记）→ 识别人物（更新实体库）→ 提取时间点（创建日历事件）
  - **需求文档工作流**：提取功能点 → 创建任务列表（带依赖关系）→ 提取验收标准 → 生成知识原子
  - **报价/方案工作流**：提取关键数据 → 关联项目 → 记录决策 → 设提醒
- 用户可自定义工作流模板（哪些步骤、什么顺序）
- 剪贴板分析后显示工作流建议卡片，一键执行

**AI 原生度**：极高 — 从"分析"升级到"执行"，闭环
**差异化**：没有竞品做到剪贴板→多步自动执行

---

### S3. 知识间隔复习 — "遗忘曲线终结者"

**痛点**：知识沉淀了但从来不回看；学过的东西忘了 80%；知识活化只是被动推荐，没有系统化复习节奏。

**方案**：
- 基于 **SuperMemo SM-2 算法**实现间隔重复：
  - 每条知识原子/记忆自动分配复习计划
  - 首次学习 → 1天后 → 3天后 → 7天后 → 14天后 → 30天后
  - 复习时 AI 出题（填空/选择/简答），根据回答质量调整下次间隔
- 每日复习清单（首页卡片 / 侧边栏入口）
- 复习统计：记忆保持率曲线、累计复习次数、各掌握度分布
- 与知识图谱联动：图谱节点颜色反映掌握度（绿→黄→红）

**AI 原生度**：高 — AI 出题 + AI 判分 + AI 调整策略
**差异化**：Anki 是手动制卡，Memora 是 AI 自动从日常笔记生成复习卡

## A 级需求（高价值，建议实现）

### A1. 项目空间 — "工作上下文一键切换"

**痛点**：任务/笔记/知识混在一起，切换项目要翻找；不同项目的知识图谱混在全局图谱里看不清。

**方案**：
- 项目维度的筛选容器：
  - 创建项目 → 绑定成员/标签/颜色
  - 切换项目 → 任务/笔记/记忆/知识原子全部按项目过滤
  - 项目级知识图谱（只看当前项目的节点和边）
  - 项目时间线（甘特图式展示项目进度）
- 项目仪表盘：完成率 / 待办数 / 知识积累趋势 / 风险提示
- 支持从剪贴板自动识别项目并关联

**AI 原生度**：中 — AI 辅助识别项目关联，人工确认
**差异化**：Notion 有数据库但无 AI 自动关联；Obsidian 无项目概念

---

### A2. 邮件/微信智能摘要 — "信息流过滤器"

**痛点**：每天大量信息涌入，重要信息淹没在噪音中；会议纪要/需求变更散落在不同渠道。

**方案**：
- **邮件接入**（IMAP）：
  - 连接邮箱 → AI 自动分类（需求/通知/讨论/紧急）
  - 关键邮件自动提取待办 → 创建任务
  - 邮件摘要推送（"3封需要你关注"）
- **微信/飞书 Webhook**：
  - 接收 Webhook 推送 → AI 提取关键信息
  - @你的消息自动转为待办
- 统一收件箱视图：邮件 + 通知 + 剪贴板 → 一个时间线

**AI 原生度**：高 — AI 分类/提取/摘要全自动
**差异化**：Superhuman 只做邮件分类，Memora 做多渠道统一+任务自动创建

---

### A3. 快照时光机 — "回溯任意时间点的知识状态"

**痛点**：知识图谱/记忆库改乱了无法回退；想看一个月前某个主题的认知状态做对比。

**方案**：
- 每日自动快照：记忆库 + 知识原子 + 图谱节点 + 任务状态的增量快照
- 时光机浏览器：
  - 时间轴拖动，查看任意日期的知识全貌
  - 对比视图：选中两个时间点，高亮差异（新增/删除/修改）
  - 回滚：恢复到某个快照状态
- 快照存储：SQLite 增量存储，30天内完整快照 + 30天后只保留每周快照

**AI 原生度**：中 — 快照自动，AI 辅助差异分析
**差异化**：Git 是代码版本，Memora 是知识版本

---

### A4. 关系人脉图谱 — "谁和谁在做什么"

**痛点**：工作关系网复杂，记不清谁负责什么；换项目后旧关系断了；需要找某领域专家时无从下手。

**方案**：
- 基于现有实体库和记忆系统扩展：
  - 人物实体自动聚合（从剪贴板/笔记/邮件中提取人物名）
  - 人物属性：角色/公司/负责项目/最近交互时间/交互频率
  - 人物关系：共事关系/上下级/协作历史
- 可视化：力导向图 + 关系卡片
- 智能推荐："你要做 K8s 相关的，可以找张三，他上次做过类似方案"
- 联系提醒："你和李四 30 天没联系了，上次讨论的 XX 项目有进展吗？"

**AI 原生度**：高 — AI 自动提取/关联/推荐
**差异化**：CRM 是手动录入，Memora 是被动自动积累

## B 级需求（有价值，可择优实现）

### B1. 语音速记 — "说一句，AI 记一切"

**痛点**：走路/开车时有想法无法打字；会议中不方便打字记录。

**方案**：
- 全局快捷键唤起语音输入
- ASR 转文字 → AI 意图识别 → 自动创建任务/笔记/记忆
- 支持 Whisper 本地模型（离线可用）

---

### B2. 知识卡片分享 — "一键生成分享卡片"

**痛点**：想分享学到的知识给同事，但目前只能导出 Markdown，不够直观。

**方案**：
- 知识原子/文章 → AI 生成精美卡片（类似小红书图文）
- 支持样式模板（简约/学术/商务）
- 一键复制到剪贴板 / 保存为图片 / 生成分享链接

---

### B3. 桌面小组件 — "待办一目了然"

**痛点**：需要打开 App 才能看今日待办，不够便捷。

**方案**：
- macOS Widget（WidgetKit）显示今日 Top 3 待办 + 番茄钟状态
- iOS Widget 同步（通过 Config Server 数据）
- Windows 任务栏悬浮窗

---

### B4. 协作批注 — "团队知识共建"

**痛点**：团队知识无法在 Memora 内协作，只能外部分享。

**方案**：
- 知识原子/文章支持批注和评论
- 批注自动转为讨论线程
- 通过 Config Server 同步批注

---

### B5. 自动标签体系 — "AI 帮你归类一切"

**痛点**：手动打标签费时，标签体系不统一；不同人对同一内容打不同标签。

**方案**：
- AI 自动生成标签（基于内容语义 + 现有标签库）
- 标签层级管理（父标签 → 子标签）
- 标签云可视化
- 跨模块标签统一（任务/笔记/记忆/知识用同一套标签）

## 优先级排序总览

| 优先级 | 需求 | 预估工期 | 核心价值 |
|--------|------|---------|---------|
| **S1** | 智能周回顾 | 1.5 周 | 每周自动总结，省 2h+ 写周报时间 |
| **S2** | 剪贴板工作流 | 2 周 | 复制→执行闭环，省 80% 重复操作 |
| **S3** | 知识间隔复习 | 1.5 周 | 解决"学了就忘"的核心痛点 |
| A1 | 项目空间 | 2 周 | 多项目并行时的上下文隔离 |
| A2 | 邮件/微信摘要 | 2 周 | 多渠道信息统一过滤 |
| A3 | 快照时光机 | 1 周 | 知识可回溯，安全感提升 |
| A4 | 关系人脉图谱 | 1.5 周 | 人脉管理自动化 |
| B1 | 语音速记 | 1 周 | 移动场景捕获想法 |
| B2 | 知识卡片分享 | 1 周 | 知识输出和传播 |
| B3 | 桌面小组件 | 1 周 | 待办可见性 |
| B4 | 协作批注 | 2 周 | 团队知识共建 |
| B5 | 自动标签体系 | 1 周 | 分类自动化 |

---

## 实施建议

**Phase 1（v3.0）**：S1 + S3 — 智能周回顾 + 间隔复习
> 理由：一个解决"回顾痛点"，一个解决"遗忘痛点"，形成**沉淀→复习→回顾**的完整闭环

**Phase 2（v3.1）**：S2 + A1 — 剪贴板工作流 + 项目空间
> 理由：从"分析"升级到"执行"，从"全局"细化到"项目"

**Phase 3（v3.2）**：A2 + A4 — 邮件摘要 + 人脉图谱
> 理由：从"内部数据"扩展到"外部信息源"

---

*以上需求基于 Memora v2.5.0 功能全貌和"AI 原生 + 本地优先 + 越用越懂你"的产品理念筛选，每个都解决真实痛点而非伪需求。*
